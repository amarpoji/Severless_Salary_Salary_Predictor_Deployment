# 💰 Serverless Salary Predictor

A full-stack Machine Learning application deployed as a Serverless Microservice on AWS. 
This project serves a Linear Regression model via a FastAPI backend, containerized with Docker, and hosted on AWS Lambda behind an API Gateway.

## 🏗️ Architecture

The project follows a cloud-native, serverless architecture:

1.  **Frontend:** A clean HTML/JS interface that sends asynchronous requests to the backend.
2.  **API Layer:** **AWS API Gateway** manages the HTTP endpoints and routing.
3.  **Compute:** **AWS Lambda** runs the application on-demand (serverless).
4.  **Container:** **Docker** packages the OS, Python runtime, dependencies, and model.
5.  **Model:** A **Scikit-Learn** Linear Regression model trained on dummy data.

## 🚀 How to Run Locally

To test the application on your own machine before deploying:

1.  **Train the Model** (Generates the `.pkl` file)

    ```bash
    python train.py
    ```

2.  **Build the Docker Container**

    ```bash
    docker build -t salary-predictor .
    ```

3.  **Run the Container**

    ```bash
    docker run -p 9000:8080 salary-predictor
    ```

4.  **Test via Terminal** (Lambda Emulation)

    ```bash
    curl -X POST "http://localhost:9000/2015-03-31/functions/function/invocations" \
    -d '{"body": "{\"years_experience\": 5}"}'
    ```

## ☁️ Deployment Guide (AWS)

Follow these steps to deploy to AWS ECR and Lambda.

### Prerequisites

  * AWS CLI installed and configured.
  * Docker Desktop running.

### Step 1: Create ECR Repository

Create a repository named `salary-predictor` in AWS Elastic Container Registry (ECR).

### Step 2: Login to ECR

```powershell
aws ecr get-login-password --region YOUR_REGION | docker login --username AWS --password-stdin YOUR_ACCOUNT_ID.dkr.ecr.YOUR_REGION.amazonaws.com
```

### Step 3: Build & Push Image

*Note: The `--provenance=false` flag is required for AWS Lambda compatibility on newer Docker versions.*

```powershell
# 1. Build
docker build --provenance=false -t salary-predictor .

# 2. Tag (Replace URI with your specific ECR URI)
docker tag salary-predictor:latest YOUR_ECR_URI:latest

# 3. Push
docker push YOUR_ECR_URI:latest
```

### Step 4: Configure Lambda Function

1.  Create a function using **Container Image**.
2.  Select the image pushed to ECR.
3.  **Important:** Go to *Configuration -\> General configuration* and update:
      * **Memory:** `512 MB`
      * **Timeout:** `30 sec`

### Step 5: Setup API Gateway

1.  Create an **HTTP API**.
2.  **Routes:** Configure two routes to handle the frontend and API correctly:
      * `ANY /` (Handles the Homepage UI)
      * `ANY /{proxy+}` (Handles API logic)
3.  Attach the Lambda integration to **both** routes.
